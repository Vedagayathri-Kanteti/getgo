# GetGo | Sports Shoes & Sports Fashion

GetGo is a web-based shopping website focused on sports footwear and sports fashion. It brings together sports shoes, athletic clothing, and activewear from popular brands in one place, providing users with a convenient way to explore different products and styles.

## Features

- Sports Footwear Collection: Explore sports shoes, running shoes, sneakers, and other athletic footwear.
- Sports Fashion: Browse sportswear, athletic tops, track jackets, trousers, and other activewear.
- Multiple Brands: Discover sports products from brands such as Nike, Adidas, Puma, Fila, and ASICS.
- Product Gallery: View product images, brand logos, and promotional videos.
- Login Interface: A dedicated page for the user login experience.
- Favourites Interface: A page for favourite products.
- Shopping Cart Interface: A dedicated page for the cart experience.
- Brand-Based Navigation: Navigate between different brand collections and product pages.

## Technologies Used

- HTML5: Website structure and content.
- CSS3: Styling, layouts, and visual design.
- JavaScript: Interactive functionality, if implemented.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the available sports footwear, sportswear, and brand pages.

For local development, you can also open the project using the Live Server extension in Visual Studio Code.

## Project Objective

The objective of GetGo is to create a dedicated online shopping interface for sports shoes and sports fashion, making it easier for users to explore athletic footwear and sportswear collections from multiple brands through a single platform.
